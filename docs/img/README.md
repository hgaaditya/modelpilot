# Screenshots

The README references four images from this folder. They don't exist yet — take them and drop them
in with these exact names.

| File | What to capture |
| --- | --- |
| `dashboard.png` | The **Dashboard** tab, whole window. Best with the stack running and a model loaded, so the status dot is green and Hardware shows real VRAM use. |
| `models.png` | The **Models** tab with **Suggest models** results showing, so the fit and estimated-speed columns are visible. |
| `coding-agents.png` | The **Coding agents** tab with the session list populated. |
| `monitoring.png` | The **Monitoring** tab after it's been open ~30s, so min/max/average columns have real spread rather than four identical numbers. |

## Taking them

The panel window is 1040x720. Capture just the window (**Alt+PrtScn** with it focused, or
Win+Shift+S), not the whole desktop — a screenshot of a 4K desktop with a small window in the
middle reads as tiny on GitHub.

## Before you commit them

**`coding-agents.png` shows your real project paths**, which usually include your Windows username
and may include client or employer names. Crop or blur anything you'd rather not publish. The same
goes for `dashboard.png` if your models directory is somewhere revealing.

Keep them under ~300 KB each; PNG at the native window size is fine, no need to upscale.
