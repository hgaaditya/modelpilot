# README images

`model-pilot-path.svg` is the checked-in visual for the public README. It shows the supported
four-step path: start the local services, choose or import a GGUF, verify a real response, then
open local chat.

Optional product screenshots can be added here later when they are captured from a representative
local installation:

| File | What to capture |
| --- | --- |
| `dashboard.png` | The **Home** tab with a model loaded, so the guided next action and live hardware state are visible. |
| `models.png` | The **Models** tab with recommendation results and the existing-GGUF path visible. |
| `monitoring.png` | The **Monitoring** tab after it has been open long enough to show non-identical min/max/average values. |

The panel window is 1040×720. Capture the window only—not an entire desktop—so it remains legible
on GitHub. Remove or obscure usernames, local paths, model names, project names, and other
identifying information before committing a capture. Keep each image under roughly 300 KB.
