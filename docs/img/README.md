# README screenshots

The public README uses these captures from a representative local installation:

| File | What it shows |
| --- | --- |
| `dashboard.png` | The **Home** tab with local services running, the guided next action, and live available-memory data. |
| `models.png` | The **Models** tab with hardware-fit recommendations and the existing-GGUF path. |
| `monitoring.png` | The **Monitoring** tab after it has collected non-identical min/max/average values. |

When replacing a capture, include the app window—not the surrounding desktop—and preserve enough
resolution for GitHub’s 960-pixel-wide display. Review every image for usernames, paths, model
names, chat content, and other identifying information before committing it.
